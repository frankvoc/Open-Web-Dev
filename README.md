# Steps for Empl App
1. Clone this repo
2. CD into empl-crud-app
3. run npm install for dependencies
4. run node app.js
5. Go to http://localhost:3000/employees
6. Test

# Steps for Auth:
Also hosted on [Render](https://open-web-dev.onrender.com/auth/login)
